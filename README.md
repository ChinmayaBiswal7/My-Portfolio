# Premium Interactive Portfolio 🚀

A high-performance, visually stunning personal portfolio built with **React**, **Framer Motion**, and **Lucide Icons**. This project features a modern Bento-grid design, custom spring physics for smooth interactions, and a professional dark-mode aesthetic.

## ✨ Key Features
- **Premium Bento Grid**: A dynamic, responsive layout for showcasing technical skills.
- **Magnetic Interactivity**: Icons that respond to cursor focus with snappy 360-degree spins and color shifts.
- **Buttery-Smooth Animations**: Hardware-accelerated (GPU) transitions powered by Framer Motion.
- **Glassmorphic UI**: Modern, translucent components with multi-layered depth and glow effects.
- **Responsive Design**: Optimized for everything from mobile phones to high-resolution monitors.

## 🛠️ Tech Stack
- **Core**: React.js
- **Styling**: Vanilla CSS (Custom Variables)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Icons**: Font Awesome (Socials)
- **Typography**: Google Fonts (Inter & Outfit)

## 🚦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ChinmayaBiswal7/My-Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
